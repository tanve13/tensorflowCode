# TensorFlow ANN Implementation

This repository contains implementations of Artificial Neural Networks (ANNs) using TensorFlow and Keras.

The project demonstrates how neural networks can be used to solve different types of machine learning problems, including:

- Binary Classification
- Multiclass Classification
- Regression

## 📌 Project Overview

The goal of this repository is to understand and implement Artificial Neural Networks using TensorFlow.

The implementations cover the complete machine learning workflow, including:

- Data preprocessing
- Exploratory data analysis
- Feature scaling
- Building neural network models
- Model training
- Model evaluation
- Making predictions
- Performance analysis

## 🧠 Implementations

### 1. Binary Classification

Binary classification is used when the target variable contains two classes.

The ANN model is trained to predict one of two possible outcomes.

Examples of evaluation techniques include:

- Accuracy
- Precision
- Recall
- Confusion Matrix
- Loss curves

### 2. Multiclass Classification

Multiclass classification is used when the target variable contains more than two classes.

The ANN learns to classify input data into one of multiple possible categories.

Evaluation includes:

- Accuracy
- Confusion Matrix
- Classification Report
- Training and validation performance

### 3. Regression

Regression is used when the target variable is continuous.

The ANN model learns the relationship between input features and a continuous target value.

Evaluation includes:

- Mean Squared Error (MSE)
- Mean Absolute Error (MAE)
- R² Score
- Prediction analysis
